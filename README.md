# Education in Danger: Global Incident Analysis (2017–2026)

### Project Overview
Attacks on education infrastructure violate fundamental human rights and disrupt civil society. This project provides a visualization of the scale of recored global attacks on educational institutions, focusing on the **human cost** and the **tactical methods** employed by various actors. The dashboard is designed as a profile to facilitate situational awareness.


The dashboard includes two global filters on the year and violence perpetrators, which filters the views accordingly. Hovering over each country in the map also provides accompanying information on the total number of incidents, the reported perpetrators, and the nature of institutions attacked.

### Data Source
---
The dataset used is **real-world data** collected by **Insecurity Insight** and hosted publicly on the **[Humanitarian Data Exchange (HDX)](https://data.humdata.org/dataset/sind-education-in-danger-monthly-news-briefs-dataset)**.
